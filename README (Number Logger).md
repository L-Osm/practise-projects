# Python project [NUMBER LOGGER]

A ready-to-run project exported from the [Programiz online compiler][programiz] - open it there to run or edit it online.

## Purpose:

First project, started on 25/10/26 on programiz, downloaded and worked on in VSC.
Records numbers entered into the system, negative and positive, decimals included.
Error handling included for all possible inputs.
Outputs the list of numbers entered, a sorted version in ascending order, the highest and lowest numbers, the mean, median, and range of the numbers.

### Future Improvements:

Allows user to select integer/float entrys only [mode initiated at start of program].
User can select type of value entered [e.g currency [all outputs will have currency signs appended], temperature, etc].
User can go back and edit previous entries.
Date/Time of 1st and last entry displayed on final screen.
Variance, S.D. and Quartiles of entries displayed.
Horizontal Bar Chart displayed for log-specific modes (e.g. currencies or temperature.)
All entries recorded onto a .txt file, including all outputs.
